# Módulo 5: IA y Ecosistema de Productividad

Exploración de modelos de lenguaje y herramientas de automatización para la eficiencia académica.

## 📅 Contenido de la Semana 5

### 1. Panorama de Modelos LLM
*   Comparativa: GPT-4o, Claude 3.5, Gemini 1.5.
*   Ventanas de contexto, tokens y capacidades de razonamiento.

### 2. IA para Investigación y Academia
*   **NotebookLM:** Creación de guías de estudio y podcasts a partir de fuentes propias.
*   **Perplexity AI:** Búsqueda con citación de fuentes en tiempo real.

### 3. IA para Desarrollo y Estructura
*   **Cursor:** Introducción al IDE diseñado para programar con IA.
*   **MCP (Model Context Protocol):** Conexión de LLMs con archivos y bases de datos locales.

### 4. Automatización de Flujos (n8n)
*   Conceptos de Nodos, Triggers y Acciones.
*   Creación de un Agente que procese información automáticamente.

### 5. Agentes y Futuro de la IA
*   Diferencia entre Chatbots y Agentes Autónomos.
*   Configuración de asistentes personales de productividad.

### 6. Ingeniería de Prompts Avanzada
*   Frameworks de prompting (Chain of Thought, Few-shot).
*   Uso de IA para la generación de código y fórmulas complejas.
