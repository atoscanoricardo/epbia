# Taller Práctico 3: Creando mi Primer Prototipo con Cursor 💻

No necesitas ser programador para crear una herramienta digital básica. Usaremos Cursor para construir una página web simple de "Calculadora de Préstamos".

## 🛠 Pasos de Construcción

### 1. Configuración
1.  Abre **Cursor**.
2.  Crea una carpeta nueva llamada `MiProyectoIA`.
3.  Crea un archivo llamado `index.html`.

### 2. Programando con Lenguaje Natural
1.  Presiona `Ctrl + K` (o `Cmd + K`) en el editor de Cursor.
2.  Escribe el siguiente prompt:
    > "Crea una página web elegante con HTML y CSS que sea una calculadora de préstamos. Debe tener campos para: Monto, Interés Anual y Plazo en meses. Debe mostrar la cuota mensual calculada. Usa colores modernos y un diseño limpio."
3.  Revisa el código que generó y dale a **Accept**.

### 3. Iteración y Mejora
1.  Abre el archivo en tu navegador.
2.  Vuelve a Cursor, selecciona el código y presiona `Ctrl + K` de nuevo.
3.  Pídele una mejora: "Agrega un botón que, al presionarlo, muestre también el total de intereses pagados al final del crédito".

---

## 🏆 El Desafío
Logra que tu página tenga un diseño que te guste y que el cálculo sea correcto (puedes verificarlo con tu Excel del Módulo 2). ¡Has creado software usando IA!
