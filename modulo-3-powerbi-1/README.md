# Módulo 3: Power BI - Nivel 1

Transformación de datos y fundamentos del modelado de inteligencia de negocios.

## 📅 Contenido de la Semana 3

### 1. Ecosistema Power BI
*   Componentes: Desktop, Service, Mobile.
*   Licenciamiento y capacidades.

### 2. Power Query Maestro (ETL)
*   Anular dinamización de columnas (Unpivot).
*   Combinar y Anexar consultas.

*   Concepto de Tablas de Hechos y Dimensiones.

### 4. Fundamentos de DAX
*   Sintaxis básica de DAX.
*   Diferencia crítica: Columnas Calculadas vs. Medidas.

### 5. Funciones DAX Esenciales
*   Agregaciones: SUM, COUNTROWS, DISTINCTCOUNT.
*   Lógica y Filtro: RELATED, DIVIDE, IF.

*   Diseño de lienzos y configuración de página.
*   Uso de Temas personalizados.
*   Gráficos básicos y Tablas de Matriz.
