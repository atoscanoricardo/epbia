# Módulo 2: Excel Avanzado

Enfoque en la transformación de datos y la automatización sin necesidad de programación profunda.

## 📅 Contenido de la Semana 2

### 1. Funciones de Búsqueda y Matrices Dinámicas
*   BUSCARX (XLOOKUP) y sus ventajas sobre BUSCARV.
*   Nuevas funciones de matriz: FILTRAR, ORDENAR, UNICOS, SECUENCIA.
*   El operador de rango derramado (#).

### 2. Lógica Avanzada y Validación
*   Validación de datos con listas dependientes (INDIRECTO).
*   Control de errores sistemático: SI.ERROR, SI.ND, ISFORMULA.

### 3. Power Query en Excel
*   Interfaz de Power Query.
*   Conexión a archivos locales, carpetas y web.
*   Transformaciones: Limpieza, quitar duplicados, reemplazar valores.

### 4. Modelado de Datos (Power Pivot)
*   Introducción al Data Model.
*   Creación de relaciones entre tablas de diferentes fuentes.

### 5. Tablas Dinámicas Pro
*   Modelos relacionales en Tablas Dinámicas.
*   Campos calculados vs. Medidas DAX simples en Excel.
*   Uso avanzado de Segmentadores y Escalas de tiempo.

### 6. Análisis de Hipótesis y Escenarios
*   Administrador de escenarios.
*   Tablas de datos (1 y 2 variables).
*   Optimización con Solver.

### 7. Automatización y Macros
*   Uso de la Grabadora de Macros.
*   Introducción al Editor de VBA.
*   Creación de Funciones Personalizadas (UDF).
