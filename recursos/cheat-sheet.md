## 📊 Excel: Atajos Imprescindibles
| Acción | Atajo (Windows) | Atajo (Mac) |
| :--- | :--- | :--- |
| **Autosuma rápida** | `Alt` + `=` | `Cmd` + `Shift` + `T` |
| **Convertir en TABLA** | `Ctrl` + `T` | `Cmd` + `T` |
| **Formato Moneda** | `Ctrl` + `Shift` + `$` | `Ctrl` + `Shift` + `$` |
| **Formato Porcentaje** | `Ctrl` + `Shift` + `%` | `Ctrl` + `Shift` + `%` |
| **Relleno Rápido (Flash Fill)** | `Ctrl` + `E` | `Ctrl` + `E` |
| **Fijar Celda (Referencias $)** | `F4` | `Cmd` + `T` |
| **Nueva Línea en Celda** | `Alt` + `Enter` | `Option` + `Return` |

## 🧪 Fórmulas y Operadores Clave

### Lógica y Búsqueda
*   `=BUSCARX(valor; rango_busqueda; rango_resultado; "Si no está")`
*   `=SI(condicion; valor_si_verdadero; valor_si_falso)`
*   `=SI.ERROR(formula; valor_si_error)`

### Estadísticas Condicionales
*   `=SUMAR.SI.CONJUNTO(rango_suma; rango_criterio1; criterio1; ...)`
*   `=CONTAR.SI.CONJUNTO(rango_criterio1; criterio1; ...)`

### Power BI (DAX)
*   **Total Ventas:** `SUM(Tabla[Columna])`
*   **Contar Filas:** `COUNTROWS(Tabla)`
*   **Seguridad:** `DIVIDE(Numerador, Denominador)`
*   **El Cerebro:** `CALCULATE([Medida], Filtro1, ...)`
