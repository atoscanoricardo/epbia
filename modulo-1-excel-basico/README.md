# Módulo 1: Excel Básico e Intermedio

Este módulo está diseñado para establecer una base técnica impecable en el manejo de hojas de cálculo.

## 📅 Contenido de la Semana 1

### 1. Arquitectura y Entorno
*   Configuración de opciones de Excel.
*   Personalización de la Cinta de Opciones y Barra de Acceso Rápido.
*   Diferencias entre formatos: .xlsx, .xlsb, .csv.

### 2. Gestión Eficiente de Datos
*   Relleno rápido (Flash Fill).
*   Creación de listas personalizadas.
*   Formatos de número personalizados (Códigos de formato).

### 3. Lógica de Referencias
*   Referencias Relativas, Absolutas y Mixtas ($).
*   Administrador de Nombres y rangos dinámicos.

### 4. Biblioteca de Funciones I
*   **Matemáticas:** SUMAR.SI.CONJUNTO, CONTAR.SI.CONJUNTO, PROMEDIO.SI.CONJUNTO.
*   **Texto:** IZQUIERDA, DERECHA, EXTRAE, HALLAR, UNIRCADENAS, LIMPIAR.
*   **Fecha y Hora:** SIFECHA, DIA.LAB, FECHA.MES, HOY, AHORA.

### 5. Formato Condicional Avanzado
*   Reglas basadas en fórmulas.
*   Barras de datos, escalas de color y conjuntos de iconos.

### 6. Tablas de Excel
*   Convertir rangos en Tablas (Ctrl+T).
*   Referencias estructuradas.
*   Diseño y Segmentación de datos en tablas.

### 7. Visualización de Datos
*   Gráficos combinados y Minigráficos.
*   Limpieza y diseño profesional de reportes.
